# Bilibili 稀有皮肤收藏馆

📁 一个用于收集与分享 B 站（哔哩哔哩）稀有皮肤的项目。

## 项目简介

本项目致力于收集 B 站在各种活动、限定合作或特殊时期发布的**稀有皮肤**，包括但不限于：

- 🎨 主题皮肤
- ✨ 动态背景
- 🎵 音效包
- 🔖 特殊光标/图标

这些皮肤大多已绝版或获取难度极高，本项目旨在为 B 站用户提供一个欣赏与研究的平台。

## 如何贡献

欢迎提交你拥有的稀有皮肤！请按以下步骤操作：

1. **Fork 本仓库**
2. **添加新皮肤**：
   - 将皮肤文件放入 `skins/` 目录
   - 在 `previews/` 目录放入预览图
   - 更新上方的皮肤列表表格
3. **提交 Pull Request**

### 提交要求

- 确保皮肤文件完整可用
- 提供清晰的预览图
- 注明皮肤名称、类型和获取方式
- 不提交侵犯版权的付费内容

## 使用说明

1. 下载你想要的皮肤文件
2. 按照对应皮肤的安装说明使用
3. 享受你的个性化 B 站体验！
